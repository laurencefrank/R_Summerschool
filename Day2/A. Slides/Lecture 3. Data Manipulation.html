The dplyr package

Data manipulation with dplyr

Main functions for data manipulation:

  • summarize(.data, ..., .by = NULL)
  • select(.data, ...)
  • filter(.data, ..., by = NULL)
  • arrange(.data, ...)
  • mutate(.data, ..., .by = NULL)

Example:

  • display the mean of mpg
summarize(.data = mtcars, mean(mpg), .by = vs)
  vs mean(mpg)
1  0  16.61667
2  1  24.55714

Why dplyr?

More intuitive and easier to read/write than base R functions

  • no need for working with square brackets


In combination with the pipe operator %>%:

  • performs a series of operations step-by-step

  • no need to write code inside-out

  • no need to make intermediate objects


Simple example of pipe operator

mtcars %>% summarize(mean(mpg))

Pipe operator %>%

Short cut key Shift + Control + M

%>% passes the (transformed) data on to the next operation

  • avoids nested code
  • avoids creation of intermediate objects


Basic principle

data %>% 
  
  perform operation A and pass on transformed data  %>% 
  
  perform operation B and pass on transformed data %>% 
  
  etc.

Example

  • base R (needs intermediate object tmp)
tmp <- data.frame(cyl   = c(4, 6),
                  mean = c(mean(mtcars[mtcars$cyl == 4, "mpg"]),
                           mean(mtcars[mtcars$cyl == 6, "mpg"])),
                  sd   = c(sd(mtcars[mtcars$cyl == 4, "mpg"]),
                           sd(mtcars[mtcars$cyl == 6, "mpg"])))
tmp[order(tmp$mean) , ]
  • dplyr
mtcars %>% 
  filter(cyl %in% c(4, 6)) %>% 
  summarize(mean = mean(mpg), sd = sd(mpg), .by = cyl) %>% 
  arrange(mean)
  cyl     mean       sd
1   6 19.74286 1.453567
2   4 26.66364 4.509828

Main dplyr functions

summarize()

The dplyr function for summarizing data

data %>% summarise(...)

  • Replace ... by a summary function, e.g.

    • mean(), median(), sd(), var(), sum() etc. for numeric variables
    • n(), n_distinct() for counts
    • many others (see help page)


mtcars %>% summarise(`mean of mpg` = mean(mpg), sd(mpg))
  mean of mpg  sd(mpg)
1    20.09062 6.026948

.by argument

  • Experimental argument
summarize(mtcars, mean(mpg), .by = vs)
  vs mean(mpg)
1  0  16.61667
2  1  24.55714
  • Alternative for the group_by() function
group_by(mtcars, vs) %>% 
  summarise(mean(mpg))
# A tibble: 2 × 2
     vs `mean(mpg)`
  <dbl>       <dbl>
1     0        16.6
2     1        24.6

select()

(De)selecting variables

  • with variable names
mtacrs %>% select(mpg, cyl)  

mtcars %>% select(-mpg, -cyl)
  • with position numbers
mtcars %>% select(-(1:2))
  • or with a function
mtcars %>% select(starts_with("d")) %>% head(2)
              disp drat
Mazda RX4      160  3.9
Mazda RX4 Wag  160  3.9

arrange()

Sort rows according to variable values

  • ascending values of cyl, and within cyl descending values of mpg
mtcars %>% arrange(cyl, -mpg)
  • pipe to display means of mpg by gear in descending order
mtcars %>% 
  group_by(gear) %>% 
  summarise(mean(mpg)) %>% 
  arrange(-`mean(mpg)`)
# A tibble: 3 × 2
   gear `mean(mpg)`
  <dbl>       <dbl>
1     4        24.5
2     5        21.4
3     3        16.1

mutate()

To compute new variables

data %>% mutate(..., .by = NULL, .keep = c("all", ...), 
                .before = NULL, .after = NULL)
  • .by groups the computations by values of a variable
  • .keep specifies which variables to return, “all”, “used”, “unused”, “none”
  • .before or .after determine where to place the new variables


Only return the new variable:

mutate(mtcars, qsec_cyl = qsec / cyl, .keep = "none") %>% 
  head(2)
              qsec_cyl
Mazda RX4     2.743333
Mazda RX4 Wag 2.836667

Saving the result of a pipeline

The examples above displayed the result, but didn’t save it

To save the result use the assignment operator

mtcars  <- mutate(mtcars, disp_cyl = disp / cyl) # overwrite original

mtcars2 <- mutate(mtcars, disp_cyl = disp / cyl) # new data frame


Don’t do anything like this

mtcars <- summarize(mtcars, mean(mpg))

  • it turns mtcars into a table and

  • the data in mtcars will be lost

Style guide

Spaces, new lines and indentation

Code with a single pipe operator on one line

  • use spaces around %>% (automatic with Control + Shift + M)
data %>% summarize(mean(x))
  • start new line after %>% in a pipe
  • indentation is automatic (or done with Ctrl + I)
data %>% 
  group_by(X) %>% 
  filter(Y > 4) %>% 
  summarize(mean(Y))

So never do something like this!!!

data%>%group_by(X)%>%filter(Y>4)%>%summarize(mean(Y))
